# VoiceLink ナレッジベース

このフォルダの資料は、STSAppでVector RAGを学習・検証するために作成した架空のサービス資料です。
実在のサービス、料金、連絡先、規約ではありません。

## 架空サービスの概要

VoiceLinkは、会議メモと短い音声メモを文字起こしし、チーム内で共有できる架空のWebサービスです。
利用者は音声ファイルをアップロードし、文字起こし結果を確認・共有できます。

## 回答時の方針

RAG実装後のGeminiには、取得した資料に書かれている内容だけを根拠に回答させます。
資料に根拠が見つからない時は、推測で補わず「資料内では確認できません」と答える想定です。
